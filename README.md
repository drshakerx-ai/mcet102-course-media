# MCET 102 Mechanical Measurements — course media

Narrated step videos and virtual labs for the MCET 102 course site (Yanbu Industrial College, Mechanical Engineering Department).

- `public/labs/` — 12 self-contained virtual labs (`MCET102_ExpNN_Virtual_Lab.html`), tested end-to-end by an automated student robot.
- `public/videos/ExpNN/` — 90 narrated step videos (≤10 s, 1280×720, H.264 + AAC).
- `public/manifest.json` — path, size and SHA-256 of every file.

The Lovable course site serves these files from its own `public/` folder (`/labs/...`, `/videos/...`).
